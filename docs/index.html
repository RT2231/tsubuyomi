要約では、読んだことにならない

法令も論文も、要約は「わかった気」を与えてくれます。でも実際に必要なのは、条文の一言一句、段落の一文一文を確かめることです。粒読みは、原文を飛ばさず、あなたのペースで一粒ずつ読み進めるための Claude スキルです。

読み方の流れ

  • 見出しと位置づけ

    条(または段落)の見出しと、全体の中で何を定めているかを一言で示します。

  • 原文 → 言い換え → 用語解説

    項・号ごとに、原文を省略せず引用し、平易な言い換えと、つまずきやすい用語の解説を添えます。

  • あなたのペースで、次へ

    「次へ」と言うまで先に進みません。質問や、前の条に戻る寄り道にも、その場で付き合います。

粒マップ

長い法令でも、いま読んでいる場所がひと目でわかります。読み終えた粒は金色に、今の粒は縁取りで示します。

対応形式

e-Gov法令検索でダウンロードできる4形式と、論文などのPDF、URL、貼り付けテキストに対応しています。複数形式が揃っている場合はXMLを正として読み、他形式は表やルビの確認に使います。

XML(e-Gov法令標準) HTML RTF PDF横一段 論文PDF URL 貼り付けテキスト

インストール

  1. tsubuyomi.skill をダウンロードする
  2. Claude.aiの設定 → Capabilities(機能)で「コード実行とファイル作成」がオンになっていることを確認する
  3. Skillsの項目から「Upload skill」でファイルを選ぶ
  4. 一覧に表示された「tsubuyomi」のトグルをオンにする

Free・Pro・Max・Team・Enterprise、いずれのプランでも利用できます。

SKILL.md と references/ フォルダを、スキルディレクトリに配置します。

git clone https://github.com/RT2231/tsubuyomi.git
cp -r tsubuyomi/{SKILL.md,references} ~/.claude/skills/tsubuyomi/

/v1/skills エンドポイントへアップロードして利用します。コード実行ツールの有効化とベータヘッダーの指定が必要です。詳しくは Agent Skills のドキュメントを参照してください。

ご利用にあたって

本スキルは、法令・論文を理解する助けを目的としており、法的助言・実務上の判断の代わりにはなりません。出力される言い換えや解説には誤りが含まれる可能性があるため、原文と必ず照合してください。現状有姿(AS IS)で無償提供しており、利用によって生じた損害について作者は責任を負いません(MIT License)。
